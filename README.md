# Student Result Management System

## About the Project
This is a Python-based web application that helps manage student marks and results.

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS

## Features
- Enter student details and marks
- Validate marks
- Calculate total and average marks
- Assign grades
- Display PASS or FAIL status
- View, edit, and delete student records

## How to Run
1. Install Python.
2. Install Flask using `pip install flask`.
3. Open the project folder in the terminal.
4. Run `python app.py`.
5. Open `http://127.0.0.1:5000` in your browser.
